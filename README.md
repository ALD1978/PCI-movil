# Ronda PCI · MILSA

App para el móvil del Departamento de PRL de MILSA TRILLO GALICIA, S.A.: revisión trimestral de extintores, botiquines y pulsadores (inspección visual), con fotos, situación en el plano, firma y PDF de evidencia.

- Dirección: https://ald1978.github.io/PCI-movil/
- Este repositorio solo contiene el **programa**. El inventario y los planos van en un archivo de datos aparte (`PCI-datos-movil_vN.json`) que PRL pasa a cada móvil. **Ese archivo nunca se sube aquí.**

## Instalar
- Android: abrir la dirección en Chrome → ⋮ → «Añadir a pantalla de inicio».
- iPhone: abrir en Safari → Compartir → «Añadir a pantalla de inicio».
- La primera vez pide el archivo de datos. Después funciona sin cobertura.

## Actualizar
- Programa: al publicarse una versión nueva, cerrar y abrir la app dos veces.
- Datos: botón «⟳ Datos» y elegir el archivo nuevo. Lo hecho en la ronda se conserva.
